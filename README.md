# Grey Graphic

Portafolio de diseño gráfico de Grey Graphic: identidad visual, fotomontaje y edición de video.

Sitio estático: `index.html` + carpeta `video/`. Se publica en Vercel sin configuración.

Para activar el botón de WhatsApp, edita en `index.html` la línea `whatsapp:''` con el número (solo dígitos, con código de país).
